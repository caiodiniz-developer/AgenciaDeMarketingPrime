# CLAUDE.md — Design System & Frontend Motion

## 1. OBJETIVO

Criar uma interface **premium, sofisticada, moderna, minimalista e cinematográfica**, com forte foco em design, tipografia, composição e motion design.

O site deve transmitir:

* Exclusividade
* Tecnologia
* Sofisticação
* Criatividade
* Confiança
* Modernidade
* Alto padrão visual

O resultado deve parecer uma experiência digital cuidadosamente desenvolvida por um estúdio de design premium.

**IMPORTANTE:** não utilizar referências visuais, linguagem, elementos ou estética relacionados a futebol, esportes ou qualquer outro segmento específico, a menos que isso seja explicitamente solicitado pelo conteúdo da página.

---

# 2. TIPOGRAFIA

## Títulos

Utilizar:

**League Spartan**

Características:

* Peso forte
* Tamanho grande
* Alto impacto visual
* Preferencialmente em MAIÚSCULO
* Letter-spacing bem ajustado
* Excelente contraste com o fundo

Os títulos devem ser uma das principais peças visuais da página.

Exemplo:

`CRIAMOS EXPERIÊNCIAS DIGITAIS`

ou

`DESIGN QUE IMPACTA`

---

## Subtítulos

Utilizar:

**Playfair Display**

A Playfair Display deve trazer contraste elegante em relação à League Spartan.

Utilizar principalmente para:

* Subtítulos
* Frases de impacto
* Pequenas chamadas
* Textos editoriais
* Destaques conceituais

Evitar utilizar Playfair Display em grandes blocos de texto.

---

# 3. PALETA DE CORES

## Dourado

Cor principal de destaque:

`#C9A84C`

Utilizar para:

* Gradientes
* Palavras-chave
* Elementos de destaque
* Bordas
* Linhas
* Ícones
* Pequenos detalhes
* Hover states
* Glow sutil
* Elementos interativos

O dourado representa sofisticação e exclusividade.

**Não exagerar no uso.**

---

## Branco

`#FFFFFF`

Utilizar para:

* Títulos
* Textos principais
* Elementos de maior importância
* Contraste

---

## Cinza

`#D9D9D9`

Utilizar para:

* Subtítulos
* Descrições
* Textos secundários
* Informações complementares

---

## Preto

O preto deve ser a principal base visual do site.

Utilizar principalmente:

`#000000`

e variações extremamente escuras, como:

`#050505`

`#0A0A0A`

`#111111`

O fundo deve criar uma sensação de profundidade e sofisticação.

---

# 4. TÍTULOS

Os títulos principais devem normalmente utilizar um gradiente entre:

`#C9A84C → #FFFFFF`

O gradiente deve ser:

* Elegante
* Suave
* Sofisticado
* Pouco saturado
* Integrado ao fundo

Evitar gradientes muito chamativos ou artificiais.

Sempre que fizer sentido, utilizar títulos em **MAIÚSCULO**.

Exemplo:

`TRANSFORME SUA PRESENÇA DIGITAL`

O título deve possuir forte presença visual sem necessariamente ocupar toda a tela.

---

# 5. SUBTÍTULOS

Os subtítulos devem utilizar:

`#FFFFFF`

ou

`#D9D9D9`

Palavras importantes podem utilizar:

`#C9A84C`

e **font-weight forte**.

Exemplo:

`Criamos experiências digitais que unem **DESIGN**, tecnologia e estratégia.`

O destaque deve ser utilizado de forma estratégica.

Não destacar palavras aleatoriamente.

---

# 6. FUNDO

O fundo principal deve ser predominantemente:

**PRETO**

Mas não deve parecer simplesmente uma página com `background: black`.

Criar profundidade através de:

* Gradientes radiais
* Gradientes sutis
* Glow dourado
* Grain/noise
* Blur
* Sombras
* Imagens estilizadas
* Elementos abstratos
* Texturas
* Formas geométricas
* Luz e contraste

Esses elementos devem ser sutis.

A estética deve continuar minimalista.

---

# 7. IMAGENS E ELEMENTOS VISUAIS

Quando forem utilizadas imagens, priorizar uma estética:

* Editorial
* Cinematográfica
* Minimalista
* Sofisticada
* Escura
* Contraste elevado
* Direção artística forte

As imagens devem conversar com o restante da composição.

Utilizar overlays escuros ou dourados quando necessário.

Não inserir imagens apenas para preencher espaço.

Cada elemento visual deve possuir uma função dentro da composição.

---

# 8. LAYOUT

O layout deve possuir bastante espaço negativo.

Priorizar:

* Grandes margens
* Espaçamento generoso
* Tipografia grande
* Hierarquia visual clara
* Composições assimétricas
* Grid sofisticado
* Sobreposição de elementos quando fizer sentido

Evitar:

* Interfaces lotadas
* Muitos cards
* Excesso de informação
* Layout extremamente centralizado em todas as seções
* Aparência de template

A composição deve parecer intencional.

---

# 9. HERO

A Hero deve ser a seção de maior impacto visual.

Priorizar:

* Título grande
* League Spartan
* MAIÚSCULO
* Gradiente dourado → branco
* Fundo preto
* Elementos visuais abstratos
* Iluminação dourada
* Motion cinematográfico
* Forte uso de espaço negativo

A Hero deve imediatamente comunicar qualidade.

Evitar a estrutura genérica:

`Título + texto + dois botões + imagem`.

Criar uma composição mais autoral.

---

# 10. CARDS

Cards devem seguir uma estética premium.

Preferir:

* Fundo preto ou quase preto
* Bordas sutis
* Dourado apenas em detalhes
* Border-radius moderado
* Sombras suaves
* Hover sofisticado

Evitar:

* Cards extremamente arredondados
* Sombras exageradas
* Gradientes excessivos
* Visual de dashboard
* Muitos elementos dentro de cada card

---

# 11. BOTÕES

Os botões devem possuir aparência premium.

Possibilidades:

### Variante 1

Fundo dourado + texto preto.

### Variante 2

Fundo preto + borda dourada + texto branco.

### Variante 3

Fundo transparente + texto branco + detalhe dourado.

Adicionar microinterações no hover.

Exemplos:

* Pequeno deslocamento
* Scale sutil
* Mudança de background
* Glow discreto
* Expansão da área visual
* Transição de cor

Evitar animações exageradas.

---

# 12. MOTION DESIGN

## REGRA PRINCIPAL

**SEGUIR O FRONTEND MOTION AGENT.**

O Frontend Motion Agent deve ser considerado a principal referência para todas as decisões relacionadas a:

* Animações
* Scroll
* Transições
* Microinterações
* Parallax
* Hover
* Entrada de elementos
* Page transitions
* Easing
* Timing
* Stagger
* ScrollTrigger
* Motion choreography

Não criar animações aleatórias.

Toda animação precisa possuir intenção.

---

# 13. FILOSOFIA DAS ANIMAÇÕES

O motion deve transmitir:

**PRECISÃO + SOFISTICAÇÃO + FLUIDEZ**

Priorizar:

* Easing natural
* Movimento orgânico
* Stagger
* Fade + transform
* Scale sutil
* Parallax
* Máscaras
* Clip-path
* Movimento baseado em scroll
* Transições cinematográficas

Evitar:

* Bounce exagerado
* Animações infantis
* Movimento constante
* Elementos pulando
* Excesso de blur
* Excesso de glow
* Muitas animações simultâneas

---

# 14. SCROLL

O scroll deve ser extremamente fluido e sofisticado.

Sempre seguir as recomendações do **Frontend Motion Agent**.

Quando fizer sentido, utilizar as tecnologias já presentes no projeto, como:

* GSAP
* ScrollTrigger
* Lenis
* Framer Motion
* CSS transitions

Não adicionar bibliotecas desnecessárias.

O scroll deve manter:

* Alto FPS
* Baixa latência
* Responsividade
* Sensação natural
* Performance

---

# 15. MICROINTERAÇÕES

As microinterações devem ser discretas.

Exemplos:

* Texto mudando de branco para dourado
* Linha dourada aparecendo
* Border animada
* Pequeno deslocamento
* Imagem ampliando levemente
* Cursor interaction
* Glow sutil
* Máscara revelando conteúdo

A interação deve parecer sofisticada, não chamativa.

---

# 16. HOVER

Hovers devem possuir transições suaves.

Exemplo:

```text
Estado normal
↓
Hover
↓
pequeno movimento
+
mudança de contraste
+
detalhe dourado
```

Evitar:

* Scale exagerado
* Rotação excessiva
* Bounce
* Mudanças bruscas
* Glow intenso

---

# 17. RESPONSIVIDADE

O design deve funcionar perfeitamente em:

* Desktop
* Notebook
* Tablet
* Mobile

Não apenas reduzir tamanhos.

Adaptar a composição.

No mobile:

* Reduzir títulos proporcionalmente
* Ajustar espaçamentos
* Simplificar elementos complexos
* Reduzir animações pesadas
* Evitar overflow horizontal
* Preservar a hierarquia visual
* Preservar a estética premium

---

# 18. PERFORMANCE

A qualidade visual nunca deve comprometer a performance.

Priorizar:

* GPU-friendly animations
* `transform`
* `opacity`
* Lazy loading
* Imagens otimizadas
* Evitar cálculos desnecessários durante scroll
* Evitar múltiplos listeners desnecessários
* Evitar animações pesadas em dispositivos móveis

Sempre considerar performance antes de adicionar um novo efeito.

---

# 19. ACESSIBILIDADE

Preservar:

* Contraste adequado
* Navegação por teclado
* Semântica HTML
* Foco visível
* Legibilidade
* `prefers-reduced-motion`

Quando o usuário possuir `prefers-reduced-motion`, reduzir ou remover animações não essenciais.

---

# 20. REGRAS VISUAIS ABSOLUTAS

### NÃO FAZER

* Não utilizar roxo.
* Não utilizar cores aleatórias.
* Não utilizar estética esportiva.
* Não utilizar referências a futebol.
* Não utilizar aparência de dashboard genérico.
* Não exagerar no dourado.
* Não exagerar em glow.
* Não colocar animações em todos os elementos.
* Não utilizar gradientes sem propósito.
* Não criar componentes visualmente desconectados.
* Não comprometer performance por efeitos.
* Não transformar o site em uma coleção de efeitos.

### FAZER

* Preto como base.
* Dourado como destaque.
* Branco para contraste.
* Cinza para informações secundárias.
* League Spartan para impacto.
* Playfair Display para elegância.
* Muito espaço negativo.
* Tipografia forte.
* Motion cuidadosamente planejado.
* Microinterações sofisticadas.
* Composições autorais.
* Seguir o Frontend Motion Agent.

---

# 21. HIERARQUIA VISUAL

Cada seção deve possuir uma hierarquia clara:

1. Título principal
2. Subtítulo
3. Conteúdo
4. Elementos secundários
5. CTA/interação

O usuário deve entender rapidamente:

**O QUE É → POR QUE IMPORTA → O QUE FAZER**

Sem precisar analisar a página inteira.

---

# 22. PRINCÍPIO FINAL

Antes de implementar qualquer seção, avaliar:

> **"Isso parece uma experiência digital premium ou apenas um template com efeitos?"**

Se parecer um template, refazer a composição.

O objetivo é criar uma experiência visual:

**PREMIUM + MINIMALISTA + MODERNA + CINEMATOGRÁFICA + TECNOLÓGICA.**

A tipografia deve ser protagonista.

O preto deve criar profundidade.

O dourado deve representar exclusividade.

O motion deve aumentar a percepção de qualidade.

E todas as decisões de animação devem seguir o **Frontend Motion Agent**.
